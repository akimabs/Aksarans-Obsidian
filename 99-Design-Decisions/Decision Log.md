# Decision Log

## D-001: Creature correspond to 20 base Aksara

Status: Accepted.

Each base aksara from HA to NGA is represented by one creature line with Evo I-III.

## D-002: Tembung is not required for basic combat

Status: Accepted.

All valid sequences can function through Core + Link. Tembung is advanced discovery/mastery.

## D-003: No exploration in core scope

Status: Accepted.

PvE can use stages directly.

## D-004: Party size target = 5

Status: Current direction.

Five creature provide a limited command vocabulary per battle.

## D-005: Max sequence length = 4

Status: Current direction.

Long enough for mastery; short enough for mobile input.

## D-006: PvE and PvP do not need identical information rules

Status: Accepted direction.

PvE can show intent. PvP uses simultaneous hidden selection / partial telegraph.

## D-007: Do not add classic element counter yet

Status: Current direction.

Combat property counters are sufficient for initial prototype.
