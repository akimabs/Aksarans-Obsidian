# Aksarans Obsidian Vault

Open this folder directly as an Obsidian vault, then start at:

`00-Start-Here/Home.md`

The vault separates accepted direction from open questions so design ideas do not accidentally become canon.

## Website

This vault is also configured to publish as a mobile-friendly website with Quartz and GitHub Pages.

After pushing the folder to a GitHub repository:

1. Open **Settings → Pages**.
2. Set **Source** to **GitHub Actions**.
3. Wait for the **Deploy Aksarans to GitHub Pages** workflow to finish.

The site will be available at:

`https://<username>.github.io/<repository>/`

The website build excludes Obsidian settings, templates, and this README. The original vault remains unchanged for local editing.
