# Glossary

| Term | Meaning |
|---|---|
| Aksara / Creature | Manifestasi karakter HA-...-NGA yang dapat dikoleksi |
| Party | Maksimal 5 creature yang dibawa ke battle |
| Sequence / Combo | Urutan 2-4 creature untuk membentuk satu aksi |
| Core | Fungsi creature ketika berada di slot pertama |
| Link | Fungsi creature ketika berada di slot 2-4 |
| Intent | Informasi rencana aksi lawan pada PvE |
| Break | Property yang efektif melawan Guard/Charge |
| Tanggah | Nama kerja untuk mechanic guard/parry/counter; belum final |
| Tembung | Sequence terkurasi yang dikenali sebagai kata/resonansi valid dan memberi bonus |
| Mastery Trait | Efek khusus Evo III yang memperdalam penggunaan creature |
| Manifestation | Creature/aksara yang sudah dimiliki player |
