# MVP Prototype

The first playable should answer one question:

> Is reading an opponent state and composing 2-4 creature commands satisfying enough to repeat?

## Include

- 5 playable creature only.
- 1 shared player HP candidate.
- 3 enemy actions: Attack, Guard, Charge.
- Core + Link composition.
- Sequence length 2-4.
- Simple speed: Fast, Normal, Slow.
- 3-5 PvE encounters.
- One sample Evo upgrade if needed to test progression feel.

## Exclude initially

- All 20 creature implementation.
- PvP networking.
- Full Tembung dictionary.
- Equipment/crafting.
- Explore/map.
- Monetization.

## Success questions

After a short playtest, can a player answer:

1. Why does order matter?
2. Why not always use four slots?
3. Why would I change my party?
4. Can I recognize one or two useful sequences from memory?
5. Did the enemy state change my decision?

If these answers are weak, adding more content will not fix the core combat.
