# Game Vision

## One-line pitch

**Creature collector turn-based di mana 20 manifestasi Aksara Jawa juga berfungsi sebagai command yang dapat dirangkai menjadi aksi.**

## Player fantasy

Player tidak sedang "mengetik kata dalam bahasa Jawa".

Player merasa sedang:

1. mengoleksi makhluk yang punya identitas kuat
2. memilih lima manifestasi yang saling melengkapi
3. membaca situasi lawan
4. merangkai command secara cepat
5. menghafal kombinasi favorit seperti mastery pada Invoker di Dota 2
6. menemukan bahwa sebagian kombinasi punya resonansi bahasa nyata bernama Tembung/Kata.

## Inspirations, bukan target clone

- **Voidpet**: attachment terhadap creature, collection, evolution.
- **Invoker**: mastery melalui kombinasi input dan muscle memory.
- **Turn-based intent combat**: keputusan didasarkan pada informasi keadaan lawan.

## Bukan ini

- Bukan game belajar Aksara Jawa yang mewajibkan pengetahuan bahasa.
- Bukan Pokemon dengan elemental chart sebagai sistem utama.
- Bukan word puzzle di mana hanya kata valid yang boleh dimainkan.
- Bukan exploration RPG pada scope awal.

## Global accessibility

Player harus dapat menikmati combat tanpa tahu bahasa Jawa.

Bahasa Jawa menjadi:

- identitas,
- lore,
- discovery,
- mastery bonus,

bukan prerequisite.
