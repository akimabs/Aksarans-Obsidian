# Content Boundaries

## In core scope

- Creature collection.
- Evolution I-III.
- Party building.
- Turn-based battle.
- Combo sequencing.
- PvE.
- PvP design.
- Tembung discovery.
- Dex/Codex.

## Explicitly not required for MVP

- Explore/map.
- Open world.
- Movement.
- Crafting.
- Equipment.
- Element chart.
- Breeding.
- Large quest system.
- Multiple currencies.

A missing system can be added later only if playtesting shows a concrete need.
