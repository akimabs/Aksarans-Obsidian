# Tembung System

## Core rule

**A sequence does not need to form a valid Javanese word to work.**

All legal 2-4 creature combinations can resolve through Core + Link rules.

## Advanced layer

Some curated sequences are recognized as **Tembung**.

When discovered:

```text
normal sequence effect
+
Tembung bonus
```

## Discovery

The first time a player uses a recognized sequence:

```text
TEMBUNG DISCOVERED
[name]
[short meaning]
[bonus effect]
```

It is then saved into [[Tembung Codex]].

## Accessibility rule

A player with zero Javanese knowledge must still be able to complete the core game.

Tembung gives:

- optimization,
- discovery joy,
- lore/language identity,
- mastery,

not basic permission to act.

## Balance

Tembung bonuses should be useful but not so dominant that external word lists become mandatory for normal play.

## Open question

How should spelling/phonology map from creature syllables to actual curated words? This needs a dedicated linguistic pass before content production.
